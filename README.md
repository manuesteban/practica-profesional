# Práctica Profesional - Módulo Técnico

Repositorio de ejercicios prácticos enfocados en análisis de datos, bases de datos y desarrollo backend.

## Estructura del Proyecto

* **`python/`**: Contiene scripts de automatización y procesamiento de datos (ej. análisis de ventas).
* **`sql/`**: Contiene las consultas, esquemas relacionales y scripts de pruebas ejecutados en MySQL Workbench.

## Tecnologías Utilizadas
* Python (Lógica de negocio y estructuras de datos)
* SQL / MySQL Workbench (Modelado DDL, DML y consultas analíticas)
* Git & GitHub (Control de versiones)
